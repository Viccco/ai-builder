# workbook

Your work from the course lands here. Claude Code writes these files as you go, so there is nothing for you to move or rename.

What shows up, roughly in order:

| File | What it is |
|---|---|
| `01-labels.json` | Your 30 verdicts and the sentence you wrote for each |
| `01-taxonomy.md` | Your named failure modes, their counts, and the decision sentence you finish with |
| `02-split.json` | Which traces you tune the judge against and which are held back |
| `02-judge-prompt.md` | The judge prompt as you wrote it |
| `02-results-round*.json` | What the judge said, one file per round |
| `02-triage.json` | Your call on each disagreement between you and the judge |
| `02-judge-notes.md` | What the held-out run showed and what you concluded |
| `checks.py` | The mechanical rules you defined, as code |
| `02-ship-call.md` | Your decision memo |

The live state of your work sits in the browser. This folder is the record, and it is what you would show someone.

Nothing here is committed by default.
