# Reference

Worked versions of every module, from one real run through the course.

**These will spoil the exercises.** Read a file only after you have finished the module it belongs to and committed to your own answer. The comparison is worth something. Reading ahead is not.

They are not answer keys. In module 1 there is no correct taxonomy, only a defensible one, and the interesting part is where yours differs.

| `02-judge-prompt.md` | your judge has been through at least two rounds |
| `02-checks.py` | you have defined your own assertion rules |
| `02-ship-call.md` | you have written your own ship memo |
